{%- comment -%} Partage LinkedIn d'un article. LinkedIn n'accepte que l'URL dans son lien de partage : le texte du post ne peut pas être pré-rempli. Le bouton fait donc deux choses d'un clic : copie le texte du post dans le presse-papiers, puis ouvre LinkedIn avec l'URL de l'article (la carte d'aperçu vient des balises Open Graph, voir head-extra.html). Il ne reste qu'à coller. Texte du post : champ `linkedin_text` du front matter ; à défaut, titre + description + hashtags des tags. Le lien n'est pas dans le texte : LinkedIn ajoute lui-même la carte de l'article. {%- endcomment -%} {%- capture default_linkedin_text -%} {{ page.title }} {{ page.description }} {% for tag in page.tags %}#{{ tag | replace: ' ', '' | replace: '.', '' | replace: '-', '' }} {% endfor %} {%- endcapture -%} {%- assign linkedin_text = page.linkedin_text | default: default_linkedin_text | strip -%}
